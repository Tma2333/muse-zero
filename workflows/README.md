# Workflows

Guided, step-by-step procedures that an AI assistant (or a human) can
execute against a Muse Zero rig: "wave the remote at the Flipper and
log every button", "sweep these GPIO pins and graph the result", and
so on.

Nothing here yet — this section opens once the bridge's workflow layer
lands (see the roadmap). Format when it does:

- One folder per workflow: `README.md` with the brief (goal, fixture
  needed, steps, what success looks like), plus any helper scripts.
- Written to be followed literally, with explicit "ask the human"
  points for anything physical (press, plug, watch for an effect).
- Transmit or emulation steps are always marked and always require a
  human go-ahead, matching the bridge's own rules.
