# Flipper scripts

Programs and content meant to run **on the Flipper itself** —
companion apps, scripted demos, and small utilities that pair with
the bridge.

Nothing here yet. House rules when content lands:

- Stock firmware only; if it needs custom firmware, it says so loudly.
- Anything here is independent of the bridge app unless it says
  otherwise, and installs the normal way (Apps folder, JS folder, …).
- Nothing in this folder transmits, emulates, or writes to tags on
  its own schedule — outputs are human-triggered, one at a time.
