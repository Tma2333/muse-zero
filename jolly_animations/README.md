# Jolly animations

Thirty-three finished desktop animation sets for the Flipper Zero — a
little robot doing little robot things. Stock firmware only: copy them
on, they join the idle rotation. Install instructions:
[SETUP.md](SETUP.md).

JollyPlane · JollyPlant · JollyPortal · JollyPotion · JollyRobot ·
JollyShell · JollySleep · JollySlime · JollyStar · JollyTeleport ·
JollyTetris · JollyUfo · JollyWrench

Format: 128×64 monochrome, 36 frames per set, 3 fps, duration 48, in
the standard `frame_N.bm` + `meta.txt` layout stock firmware reads
from `/ext/dolphin/`, registered in the included `manifest.txt`. One
retired early draft lives in [`retired/`](retired/) — it's not in the
manifest.
